Thine uses a proven **agentic loop**: read your codebase, call tools, edit files, run commands, and iterate until the task is done. **Thine Runtime** sits between the Thine agent and your LLM backend — translating requests, applying middleware, and recording telemetry.

## Stack

```text
┌─────────────────────────────────────────────────────────────────┐
│  Terminal: `thine`                IDE: `thine-runtime ide`       │
│  Thine agent (REPL + tools)       Thine IDE + agent composer    │
└────────────────────────────┬────────────────────────────────────┘
                             │  POST /v1/messages
                             │  GET  /v1/models
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│  Thine Runtime (:8787)                                           │
│  · Anthropic-compatible API façade                               │
│  · Model alias mapping (thine model names → backend models)      │
│  · Thine middleware (cache, repo graph, tool pruning, …)           │
│  · Telemetry → Postgres → /__thine dashboard                     │
└────────────────────────────┬────────────────────────────────────┘
                             │  translate to provider format
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│  Backend: Gemini · OpenAI · openai-responses · Ollama · …       │
└─────────────────────────────────────────────────────────────────┘
```

## Agent loop

1. **User prompt** enters via REPL, `-p`, or Thine Agent SDK `query()`
2. **Thine agent** assembles system prompt, project memory, skills, and tool definitions
3. **Request** hits Thine Runtime
4. **Middleware** may inject repo symbols, memory, prune tools, escalate model, etc.
5. **Gateway** translates to provider API and streams the response back
6. **Tools** execute (Read, Edit, Bash, MCP, Agent, …)
7. Loop continues until the model stops or limits hit

## What lives where

| Layer | Component |
| --- | --- |
| Agent loop, tools, bash, git | Thine agent |
| MCP, skills, hooks, plugins | Thine agent |
| `/v1/messages` gateway | Thine Runtime |
| Provider translation | Thine Runtime |
| Token middleware | Thine Runtime |
| Telemetry dashboard | Thine Runtime |

## Middleware routes

| Route | Middleware |
| --- | --- |
| `/v1/messages` | Thine profile (default) |
| `/official/v1/messages` | Off — passthrough only |
| `X-Thine-Middleware: off` header | Off for that request |

## Workspace index

On launch, Thine can build `.thine/index/workspace.json` for repository graph injection:

```bash
thine index              # build if missing or stale
thine index --force      # rebuild
```
