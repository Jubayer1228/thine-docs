Thine Runtime routes Thine through a **configurable backend** in `~/.config/thine-runtime/config.json`. Set your provider API key in the environment — keys are not stored in config.

## Runtime backend types

| `backend.type` | API key env | Example `defaultModel` |
| --- | --- | --- |
| `gemini` | `GEMINI_API_KEY` | `gemini-2.5-flash` |
| `openai-compatible` | `OPENAI_API_KEY` | `gpt-4o-mini` |
| `openai-responses` | `OPENAI_API_KEY` | `gpt-5.1-codex-mini` |
| `ollama` | (none) | `llama3.2` |
| `anthropic-forward` | `ANTHROPIC_API_KEY` | `claude-sonnet-4-6` |

Example configs: `config/` in your Thine Runtime install directory.

Install with the right profile:

```bash
./scripts/install.sh                  # Gemini
./scripts/install.sh --backend codex  # OpenAI Codex mini
```

## Gemini

```json
{
  "defaultModel": "gemini-2.5-flash",
  "backend": {
    "type": "gemini",
    "baseUrl": "https://generativelanguage.googleapis.com/v1beta/openai"
  }
}
```

```bash
export GEMINI_API_KEY=your-key
```

## OpenAI / Codex

```json
{
  "defaultModel": "gpt-5.1-codex-mini",
  "backend": {
    "type": "openai-responses",
    "baseUrl": "https://api.openai.com/v1"
  }
}
```

```bash
export OPENAI_API_KEY=your-key
```

## Ollama (native passthrough)

```json
{
  "defaultModel": "llama3.2",
  "backend": {
    "type": "ollama",
    "baseUrl": "http://127.0.0.1:11434"
  }
}
```

Ollama speaks Anthropic natively — no translation layer.

## OpenAI-compatible gateways

Point at LiteLLM, vLLM, or an internal gateway:

```json
{
  "defaultModel": "your-model",
  "backend": {
    "type": "openai-compatible",
    "baseUrl": "https://your-gateway/v1"
  }
}
```

## Model aliases

Thine sends names like `claude-sonnet-4-6`. Map them in config:

```json
"claudeCode": {
  "modelAliases": {
    "claude-sonnet-4-6": "gpt-4o",
    "claude-haiku-4-20250514": "gpt-4o-mini"
  }
}
```

See [Configuration](/en/runtime/configuration).

## Legacy: legacy Thine fork providers

The [legacy Thine fork](https://github.com/thine-ai/thine-code) uses env-var provider selection inside the modified CLI. Prefer the runtime gateway path above for new projects.

### Fork provider table

| Provider | Select | API key env | Default model | Base URL |
| --- | --- | --- | --- | --- |
| **Gemini** | `CLAUDE_CODE_LLM_PROVIDER=gemini` or `CLAUDE_CODE_USE_GEMINI=1` | `GEMINI_API_KEY`, `GOOGLE_API_KEY` | `gemini-2.5-flash` | Google Generative Language API |
| **OpenAI** | `CLAUDE_CODE_LLM_PROVIDER=openai` | `OPENAI_API_KEY` | `gpt-4o-mini` | `https://api.openai.com/v1` |
| **DeepSeek** | `deepseek` (auto-detect) | `DEEPSEEK_API_KEY` | `deepseek-chat` | `https://api.deepseek.com/v1` |
| **Qwen** | `qwen` | `DASHSCOPE_API_KEY`, `QWEN_API_KEY` | `qwen-plus` | DashScope compatible mode |
| **Kimi** | `kimi` | `MOONSHOT_API_KEY`, `KIMI_API_KEY` | `moonshot-v1-8k` | Moonshot API |
| **GLM** | `glm` | `ZHIPU_API_KEY`, `GLM_API_KEY` | `glm-4.5-air` | Zhipu BigModel |
| **Ollama** | `ollama` | (optional) | `llama3.2` | `http://localhost:11434/v1` |
| **Custom** | `openai-compatible` | `OPENAI_COMPATIBLE_API_KEY` | — | `OPENAI_COMPATIBLE_BASE_URL` |

## Auto-detection

When **only one** provider-specific API key is set in the environment, Thine picks the backend automatically — no flag required.

## Model overrides

```bash
export CLAUDE_CODE_LLM_MODEL=gemini-2.5-pro
# or
export ANTHROPIC_MODEL=gpt-4o   # remapped to your universal model
```

Thine model aliases (`sonnet`, `opus`, `haiku`, `claude-*`) are **remapped** to your configured backend model so skills and commands keep working.

## Gemini quick start

```bash
export CLAUDE_CODE_USE_GEMINI=1
export GEMINI_API_KEY=your-key
export CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS=1
```

Native Gemini streaming and prompt caching are enabled by default. Set `CLAUDE_CODE_GEMINI_USE_OPENAI=1` to force the OpenAI-compatible endpoint instead.

## OpenAI-compatible gateways

Point at LiteLLM, vLLM, or an internal gateway:

```bash
export CLAUDE_CODE_LLM_PROVIDER=openai-compatible
export OPENAI_COMPATIBLE_BASE_URL=https://your-gateway/v1
export OPENAI_COMPATIBLE_API_KEY=your-key
export OPENAI_COMPATIBLE_MODEL=your-model
```

## Web search

Universal providers use Tavily for the WebSearch tool:

```bash
export TAVILY_API_KEY=tvly-...
# or
export CLAUDE_CODE_TAVILY_API_KEY=tvly-...
```

## Fallback model

In print mode, chain a fallback when the primary model is overloaded:

```bash
thine -p --fallback-model gemini-2.5-flash "your prompt"
```
