---
title: Subagents
description: Spawn isolated agents for parallel work with the Agent tool.
---

Subagents run in isolated context with their own tool access. See upstream: [Create custom subagents](https://code.claude.com/docs/en/sub-agents).

## Built-in types

- `general-purpose` — default exploration agent
- Custom agents from `.claude/agents/` or plugins

## Nested subagents

Upstream supports sub-agents spawning sub-agents (capped depth). In external Thine builds, `FORK_SUBAGENT` may be off by default — enable in `shims/bun-bundle.ts` for your distribution.

## Agent tool

The main session invokes subagents via the **Agent** tool. Results stream back as task notifications.
