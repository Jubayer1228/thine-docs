The Thine Agent SDK exposes the same agent loop as the CLI through a programmatic API. Use it to build automation, CI pipelines, custom UIs, and backend services — backed by **any configured LLM provider**.

This fork implements a real SDK (not a stub): `query()` streaming, session persistence, and subprocess isolation.

## Install

From the `thine-code/claude` package:

```bash
cd thine-code/claude
bun install && bun run build
```

TypeScript import path (after build):

```typescript
import { query } from './sdk/index.js'
```

## Minimal example

```typescript
import { query } from '@anthropic-ai/claude-code-gemini/sdk'

for await (const message of query({
  prompt: 'Find and fix the bug in auth.ts',
  options: {
    cwd: '/path/to/repo',
    permissionMode: 'bypassPermissions', // or 'default'
    maxTurns: 10,
  },
})) {
  if (message.type === 'assistant') {
    console.log(message.message)
  }
  if (message.type === 'result') {
    console.log('Done:', message.result)
  }
}
```

Set provider env vars before running (`GEMINI_API_KEY`, etc.) — see [Providers](/en/providers).

| | Thine SDK | Anthropic Agent SDK |
| --- | --- | --- |

| Subprocess runtime | Yes | Yes |
