The Thine Agent SDK exposes the same agent loop as the `thine` CLI through a programmatic API. In the Thine stack, the **Thine IDE** and `thine-agent` extension use the SDK → Thine Runtime → your backend.

## Thine IDE path (recommended)

```bash
thine-runtime ide doctor
thine-runtime ide .
```

The in-editor agent uses Thine Agent SDK → `http://127.0.0.1:8787` → your provider. No vendor subscription required in the client.

## Standalone SDK

For programmatic use outside the IDE, use the Thine Agent SDK from the [Thine IDE repo](https://github.com/thine-ai/thine-code) with `ANTHROPIC_BASE_URL` pointing at Thine Runtime.

The SDK implements `query()` streaming, session persistence, and subprocess isolation.

## Minimal example

```typescript
import { query } from '@thine/agent-sdk'

for await (const message of query({
  prompt: 'Find and fix the bug in auth.ts',
  options: {
    cwd: '/path/to/repo',
    permissionMode: 'bypassPermissions',
    maxTurns: 10,
  },
})) {
  if (message.type === 'assistant') {
    console.log(message.message)
  }
  if (message.type === 'result') {
    console.log('Done:', message.result)
  }
}
```

Set provider env vars before running (`GEMINI_API_KEY`, etc.) — see [Providers](/en/providers).

## Thine Agent SDK vs vendor SDK

| | Thine Agent SDK | Vendor-only SDK |
| --- | --- | --- |
| `query()` streaming | Yes | Yes |
| Subprocess runtime | Yes | Yes |
| Single-vendor subscription | No | Often yes |
| Multi-provider backends | Yes | Limited |
