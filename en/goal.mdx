---
title: Keep Thine working toward a goal
description: Set a completion condition and let Thine keep working until tests pass, lint is clean, or your criteria hold.
---

The `/goal` command sets a completion condition. Thine keeps iterating until the condition is satisfied or limits are hit.

## Usage

In an interactive session:

```
/goal all tests pass
/goal lint is clean and types check
```

## With print mode

```bash
thine -p "/goal npm test exits 0 — fix any failures" --dangerously-skip-permissions
```

## Tips

- Be specific about what "done" means (exit codes, file paths, command output).
- Combine with `--max-turns` to cap iteration count in scripts.
