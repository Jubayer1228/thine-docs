Thine Code releases track the upstream Claude Code fork version with a `-gemini` or Thine suffix (e.g. `2.1.88-gemini`).

## Recent Thine changes

See the [what's new](/en/whats-new) digest and [feature parity](/en/whats-new/feature-parity) matrix for fork-specific work:

- Multi-provider LLM presets (Gemini, OpenAI, DeepSeek, Qwen, Kimi, GLM, Ollama)
- Universal prompt caching
- `/goal`, `/cd`, `mcp login/logout`, `--plugin-url`
- Thine branding and API-key auth
- Agent SDK (`query()`, sessions, subprocess runtime)
