## Thine Runtime

Track releases on [thine.ai](https://thine.ai) when public distribution is live.

Recent themes:

- Thine gateway with multi-provider backends (Gemini, OpenAI, Ollama)
- Research middleware (cache, repo graph, tool pruning, memory, escalation)
- Thine dashboard telemetry at `/__thine`
- `thine` CLI installer and `thine doctor`
- Thine IDE integration via `thine-runtime ide`
