---
title: Project memory
description: Give Thine persistent instructions with THINE.md, CLAUDE.md, and Thine auto memory.
---

Thine reads **project memory files** from your repository at session start. Use **`THINE.md`** for Thine-native projects, or **`CLAUDE.md`** for compatibility with existing repos.

## Quick example

Create `THINE.md` (or `CLAUDE.md`) in your repo root:

```markdown
# Project instructions

- Use bun, not npm
- Run `bun test` before committing
- Prefer editing existing files over creating new ones
```

## Scopes

| Location | Scope |
| --- | --- |
| `./THINE.md` or `./CLAUDE.md` | Project |
| `~/.thine/THINE.md` or `~/.claude/CLAUDE.md` | User-global |
| Nested dirs | Loaded when tools access those paths |

<Info>
  Thine accepts both `THINE.md` and `CLAUDE.md`. New projects should prefer `THINE.md`.
</Info>

## Thine persistent memory (middleware)

Thine Runtime can additionally inject `.thine/memory/MEMORY.md` summaries when `persistentMemory` is enabled in config. This is separate from project memory files — see [Middleware](/en/runtime/middleware).

## Auto memory

When enabled in Thine settings, auto memory persists learnings across sessions (build commands, debugging notes).
