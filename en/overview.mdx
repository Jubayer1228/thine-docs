Thine is an AI-powered coding assistant that understands your entire codebase and works across multiple files and tools to help you build features, fix bugs, and automate development tasks. Choose **any supported LLM backend** — not a single vendor subscription.

```text
Thine CLI (`thine`)              Thine Runtime (:8787)          Your model
interactive agent + tools          gateway + middleware           (Gemini, OpenAI, …)
        │                                  │                           │
        │  Read, Edit, Bash, MCP, Agent    │  translate + optimize     │
        └──────────────────────────────────┴───────────────────────────┘
```

Thine Runtime is the gateway and middleware layer. The **Thine agent** owns the tool loop, MCP, hooks, skills, and subagents.

## Get started

<Steps>
  <Step title="Install Thine">
    ```bash
    curl -fsSL https://claude.ai/install.sh | bash                              # Claude Code (agent harness)
    curl -fsSL https://storage.googleapis.com/robinailabs-dist/install.sh | bash  # Thine
    ```

    The same installer is served from `https://robinailabs.com/install.sh` once DNS is live. Use `--install-claude` to install the Claude Code CLI automatically. See [Quickstart](/en/quickstart).

    Puts `thine` and `thine-runtime` in `~/.local/bin` and creates `~/.config/thine-runtime/config.json`.
  </Step>
  <Step title="Set your API key">
    ```bash
    export GEMINI_API_KEY=your-key
    # or for Codex profile:
    export OPENAI_API_KEY=your-key
    ```

    See [Providers](/en/providers) for all backends.
  </Step>
  <Step title="Verify">
    ```bash
    thine doctor
    ```
  </Step>
  <Step title="Run on any project">
    ```bash
    cd your-project
    thine -p "Read README.md and summarize this repo" --dangerously-skip-permissions
    ```
  </Step>
</Steps>

<Info>
  Thine uses **your provider API keys** (Gemini, OpenAI, etc.) — routed through Thine Runtime at `http://127.0.0.1:8787`.
</Info>

## What you can do

<AccordionGroup>
  <Accordion title="Build features and fix bugs" icon="hammer">
    Describe what you want in plain language. Thine plans the approach, writes code across multiple files, and verifies it works.

    ```bash
    thine -p "fix the auth middleware bug and add a regression test" --dangerously-skip-permissions
    ```
  </Accordion>

  <Accordion title="Use any LLM provider" icon="sparkles">
    Route the same agent loop through Gemini, OpenAI (including Codex/GPT-5), Ollama, or any OpenAI-compatible API.

    [Providers →](/en/providers)
  </Accordion>

  <Accordion title="Thine middleware" icon="bolt">
    Token-efficient gateway hooks — instruction cache, repository graph, tool pruning, persistent memory, model escalation, and more.

    [Middleware →](/en/runtime/middleware)
  </Accordion>

  <Accordion title="Thine dashboard" icon="chart-line">
    Session-grouped logs, per-turn token breakdown, middleware notes, and cost analytics at `http://127.0.0.1:8787/__thine`.

    [Dashboard →](/en/runtime/dashboard)
  </Accordion>

  <Accordion title="Thine IDE" icon="code">
    Open the Thine editor with the agent composer — Thine Agent SDK → runtime → your model.

    thine-runtime ide doctor

  </Accordion>

  <Accordion title="MCP, skills, and hooks" icon="plug">
    Connect databases, APIs, and custom tools. Package repeatable workflows as skills. Automate with shell hooks.

    [MCP](/en/mcp) · [Skills](/en/skills) · [Hooks](/en/hooks-guide)
  </Accordion>

  <Accordion title="Pipe, script, and automate" icon="terminal">

## Thine vs generic gateways

| Capability | Thine | Generic OpenAI proxy |
| --- | --- | --- |
| Full agent loop + tools | Yes | Depends on client |
| MCP, skills, hooks, subagents | Yes | Client-dependent |
| Multi-provider backends | Yes | Usually single vendor |
| Research middleware | Yes | No |
| Session telemetry dashboard | Yes | Rare |
| Workspace symbol index | Yes | No |
