Thine Code is an AI-powered coding assistant built on the Claude Code agent loop. It understands your entire codebase and can work across multiple files and tools to get things done — while letting you choose **any supported LLM backend** instead of being locked to Anthropic.

Thine Code is a fork of [Claude Code](https://code.claude.com/docs/en/overview) with multi-provider routing, API-key auth, and Thine branding. Most CLI features, skills, hooks, MCP, and the Agent SDK work the same way as upstream.

## Get started

Choose your provider and install the CLI:

<Steps>
  <Step title="Install Thine Code">
    Build from source or install your team's packaged binary:

    ```bash
    git clone https://github.com/thine-ai/thine-code.git
    cd thine-code/claude
    bun install && bun run build
    ```

    The CLI binary is `dist/cli.mjs`. Alias it as `thine` or `claude` during the transition period.
  </Step>
  <Step title="Set your API key">
    ```bash
    export CLAUDE_CODE_USE_GEMINI=1
    export GEMINI_API_KEY=your-key
    export CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS=1
    ```

    See [Providers](/en/providers) for OpenAI, DeepSeek, Qwen, Kimi, GLM, and Ollama.
  </Step>
  <Step title="Start a session">
    ```bash
    cd your-project
    node /path/to/thine-code/claude/dist/cli.mjs
    ```

    Or use `-p` for non-interactive output:

    ```bash
    node dist/cli.mjs -p "explain this repo"
    ```
  </Step>
</Steps>

<Info>
  Thine Code uses **API keys** instead of Anthropic OAuth. Set `GEMINI_API_KEY`, `OPENAI_API_KEY`, or another provider key — see [Quickstart](/en/quickstart).
</Info>

## What you can do

Here are some of the ways you can use Thine Code:

<AccordionGroup>
  <Accordion title="Build features and fix bugs" icon="hammer">
    Describe what you want in plain language. Thine Code plans the approach, writes code across multiple files, and verifies it works.

    ```bash
    thine -p "fix the auth middleware bug and add a regression test"
    ```
  </Accordion>

  <Accordion title="Use any LLM provider" icon="sparkles">
    Route the same agent loop through Gemini, OpenAI, DeepSeek, Qwen, Kimi, GLM, or a local Ollama instance. Model aliases like `sonnet` map to your configured backend.

    [Providers guide →](/en/providers)
  </Accordion>

  <Accordion title="Connect your tools with MCP" icon="plug">
    The [Model Context Protocol (MCP)](/en/mcp) connects Thine Code to external data sources — databases, APIs, issue trackers, and custom tools.

    Authenticate HTTP/SSE servers from the shell:

    ```bash
    thine mcp login my-server
    ```
  </Accordion>

  <Accordion title="Customize with CLAUDE.md, skills, and hooks" icon="sliders">
    [`CLAUDE.md`](/en/memory) gives Thine persistent project instructions. [Skills](/en/skills) package repeatable workflows. [Hooks](/en/hooks-guide) run shell commands before or after agent actions.
  </Accordion>

  <Accordion title="Run agents and work toward a goal" icon="users">
    Spawn [subagents](/en/subagents) for parallel work. Use [`/goal`](/en/goal) to set a completion condition and let the agent keep working until tests pass, lint is clean, or your criteria hold.
  </Accordion>

  <Accordion title="Pipe, script, and automate with the CLI" icon="terminal">
    Thine Code follows the Unix philosophy — pipe logs, run in CI, chain with git:

    ```bash
    git diff main --name-only | thine -p "review these files for security issues"
    ```

    See the [CLI reference](/en/cli-reference) for all commands and flags.
  </Accordion>
</AccordionGroup>

## Thine vs Claude Code

| Capability | Thine Code | Claude Code (Anthropic) |
| --- | --- | --- |
| Agent loop, tools, skills, hooks | Yes | Yes |
| MCP, plugins, subagents | Yes | Yes |
| Multi-provider LLM (Gemini, OpenAI, …) | Yes | Third-party via Bedrock/Vertex only |
| Anthropic OAuth / claude.ai subscription | Optional fallback | Primary |
| Artifacts, Routines, cloud ultrareview | No (cloud-only upstream) | Yes |
| Agent SDK (`query()`, sessions) | Yes | Yes |

See [Feature parity](/en/whats-new/feature-parity) for a detailed audit against upstream [what's new](https://code.claude.com/docs/en/whats-new).
