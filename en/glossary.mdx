---
title: Glossary
description: Definitions for Thine Code and agentic coding terminology.
---

| Term | Definition |
| --- | --- |
| **Agentic loop** | Model ↔ tool execution cycle until task completes |
| **CLAUDE.md** | Project instruction file read each session |
| **Compaction** | Summarizing old context to free window space |
| **MCP** | Model Context Protocol — external tool servers |
| **Skill** | Reusable slash-command workflow |
| **Subagent** | Isolated agent spawned by the Agent tool |
| **Print mode** | `-p` non-interactive CLI output |
| **Universal LLM** | Thine adapter routing to non-Anthropic APIs |
| **Session** | Persisted conversation with UUID |
