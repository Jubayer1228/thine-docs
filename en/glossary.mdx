---
title: Glossary
description: Definitions for Thine and agentic coding terminology.
---

| Term | Definition |
| --- | --- |
| **Thine** | Agentic coding product — CLI, tools, MCP, skills |
| **Thine Runtime** | Gateway at `:8787` — translation, middleware, telemetry |
| **Thine IDE** | Editor with integrated Thine agent composer |
| **Thine Agent SDK** | Programmatic `query()` API for automation |
| **Thine dashboard** | Telemetry UI at `/__thine` |
| **Agentic loop** | Model ↔ tool execution cycle until task completes |
| **THINE.md** | Thine project instruction file (preferred) |
| **CLAUDE.md** | Compatible project memory filename |
| **Compaction** | Summarizing old context to free window space |
| **MCP** | Model Context Protocol — external tool servers |
| **Skill** | Reusable slash-command workflow |
| **Subagent** | Isolated agent spawned by the Agent tool |
| **Print mode** | `-p` non-interactive CLI output |
| **Session** | Persisted conversation with UUID |
