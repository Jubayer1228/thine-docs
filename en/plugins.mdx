title: Plugins
description: Discover, install, and load plugins to extend Thine.
---

Plugins bundle skills, agents, hooks, MCP servers, and LSP configs.


## Session-only plugins

```bash
# Directory
thine --plugin-dir ./my-plugin

# Zip archive
thine --plugin-dir ./my-plugin.zip

# From URL
thine --plugin-url https://example.com/my-plugin.zip
```

## Manage installed plugins

```bash
thine plugin list
thine plugin install name@marketplace
```

In-session: `/plugin`
