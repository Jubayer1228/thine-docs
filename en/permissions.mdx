## Rules syntax

```json
{
  "permissions": {
    "allow": [
      "Bash(git diff:*)",
      "Bash(npm test:*)",
      "Read",
      "Edit"
    ],
    "deny": [
      "Bash(curl:*)",
      "WebSearch"
    ]
  }
}
```

## Tool parameter matching

Deny or ask on specific parameters (upstream week 25+):

```
Agent(model:opus)
Bash(rm -rf:*)
```
