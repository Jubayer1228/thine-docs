## Working on Gemini / universal providers

| Feature | Notes |
| --- | --- |
| `mcp login` / `logout` | CLI OAuth for HTTP/SSE MCP |
| Shell mode (`! cmd`) | Bash mode via `!` prefix |
| `/rewind` after `/clear` | Parent session preserved |
| `/cd` | Mid-session cwd change |
| `/goal` | Completion condition + auto-continue |
| `/code-review` | Alias for `/review` |
| `/config`, `/usage`, `/loop` | Settings and token UI |
| `--safe-mode`, `--fallback-model` | CLI flags |
| `--plugin-dir`, `--plugin-url` | Zip and URL plugins |
| `project purge`, `agents --json` | Extended CLI |
| Multi-provider presets | `llmPresets.ts` |
| PowerShell tool | Windows native shell |
| Tool(param:value) permissions | Pattern-based rules |

| Auto mode classifier | `CLAUDE_CODE_TRANSCRIPT_CLASSIFIER=1` |
