Thine ships a complete agentic coding stack: the **Thine agent** (tools, MCP, hooks, skills), **Thine Runtime** (gateway + middleware), and the **Thine dashboard** (telemetry).

## Summary

| Category | Status | Notes |
| --- | --- | --- |
| **Agent loop + tools** | Yes | Read, Edit, Bash, Grep, Agent, MCP |
| **MCP, skills, hooks, plugins** | Yes | Full extensibility |
| **Subagents, `/goal`, `/review`** | Yes | Parallel and goal-driven work |
| **Multi-provider backend** | Yes | Gemini, OpenAI, Ollama via gateway |
| **Thine middleware** | Yes | Cache, repo graph, tool pruning, escalation |
| **Thine dashboard** | Yes | `/__thine` with Postgres |
| **Thine IDE** | Yes | `thine-runtime ide` |
| **Cloud artifacts / routines** | No | Vendor cloud only |

## Core Thine features

| Feature | Notes |
| --- | --- |
| `thine` REPL + `-p` print mode | Primary CLI entry point |
| `thine doctor` | Health, backend, middleware routes |
| `thine index` | Workspace symbol index for repo graph |
| `mcp login` / `logout` | OAuth for HTTP/SSE MCP |
| `/goal`, `/review`, `/config` | Slash commands in REPL |
| `--no-middleware` | Gateway passthrough |
| Model aliases | `claude-sonnet-4-6` → your backend model |
| Auto model escalation | Middleware on knowledge-read tasks |
| Session telemetry | Per-turn tokens, tools, middleware notes |

## Thine middleware

| Flag | Effect |
| --- | --- |
| `instructionCache` | Fingerprint system+tools for cache tracking |
| `repositoryGraph` | Inject symbols from `.thine/index/` |
| `toolPruning` | Send task-relevant tools only |
| `persistentMemory` | Inject `.thine/memory/MEMORY.md` |
| `kvCache` | Provider prefix caching |
| `toolResultCompaction` | Compact old tool results |

See [Middleware](/en/runtime/middleware).

## Optional features

| Feature | Notes |
| --- | --- |
| Auto mode classifier | `CLAUDE_CODE_TRANSCRIPT_CLASSIFIER=1` |
| Background agents (`--bg`) | Requires tmux |
| Computer use / web browser | MCP-dependent |
| `/ultrareview` | Local review; cloud fleet not included |

## Verify your setup

```bash
thine doctor
thine -p "Reply with exactly: THINE_OK" --dangerously-skip-permissions
curl -s http://127.0.0.1:8787/health | jq .
```
