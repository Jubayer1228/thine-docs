Welcome to Thine! This guide gets you from zero to a working session in a few minutes.

## Prerequisites

- **Node.js 20+**
- The official **Claude Code CLI** — Thine drives it as the agent harness:
  ```bash
  curl -fsSL https://claude.ai/install.sh | bash
  ```
  (or pass `--install-claude` to the Thine installer below)
- An API key from at least one provider ([Gemini](https://aistudio.google.com/apikey), [OpenAI](https://platform.openai.com/api-keys), etc.)
- A git repository or project directory to work in

## 1. Install Thine

One line — served from the hosted release today, and from `robinailabs.com` once DNS is live:

```bash
curl -fsSL https://storage.googleapis.com/robinailabs-dist/install.sh | bash
```

```bash
# Same installer via the custom domain (when live):
curl -fsSL https://robinailabs.com/install.sh | bash
```

**Options** (append after `bash -s --`):

```bash
# OpenAI Codex profile instead of Gemini
curl -fsSL https://storage.googleapis.com/robinailabs-dist/install.sh | bash -s -- --backend codex

# Install the Claude Code CLI at the same time
curl -fsSL https://storage.googleapis.com/robinailabs-dist/install.sh | bash -s -- --install-claude
```

**Local checkout (developers):**

```bash
cd thine-runtime
./scripts/install.sh                  # Gemini profile (default)
./scripts/install.sh --backend codex  # OpenAI Codex mini profile
```

**Publish a new release (maintainers):**

```bash
npm run package:release   # creates dist/thine-runtime-<version>.tar.gz
# then upload install.sh + tarball + releases/latest.txt to the dist host
```

Install puts `thine` and `thine-runtime` in `~/.local/bin` and creates `~/.config/thine-runtime/config.json`.

## 2. Set your API key

**Gemini (default profile):**

```bash
export GEMINI_API_KEY=your-key-here
```

**OpenAI / Codex (if you used `--backend codex`):**

```bash
export OPENAI_API_KEY=your-key-here
```

Add the export to `~/.zshrc` so new shells pick it up.

## 3. Verify installation

```bash
thine doctor
```

Expected: Thine Runtime reachable on `:8787`, backend ping OK, middleware routes listed.

```bash
curl -s http://127.0.0.1:8787/health | jq .
```

## 4. Run your first task

**One-shot (print mode):**

```bash
cd ~/your-project
thine -p "list the top-level directories and summarize the project" --dangerously-skip-permissions
```

**Interactive REPL:**

```bash
thine
```

**Gateway passthrough only (no Thine middleware):**

```bash
thine --no-middleware -p "reply with exactly: passthrough-ok" --dangerously-skip-permissions
```

## 5. Try slash commands

In an interactive session:

| Command | What it does |
| --- | --- |
| `/help` | List available commands |
| `/config` | View or change settings |
| `/model` | Switch model alias |
| `/goal <condition>` | Keep working until condition holds |
| `/review` | Code review workflow |

## Manual two-terminal setup

Terminal 1 — start Thine Runtime:

```bash
thine-runtime start
```

Terminal 2 — launch the Thine agent:

```bash
thine -p "summarize this repo" --dangerously-skip-permissions
```

`thine` starts the gateway automatically if it is not already running.

## Open the Thine dashboard

With Postgres telemetry enabled in config:

```
http://127.0.0.1:8787/__thine
```

Default auth: `Authorization: Bearer thine`

See [Dashboard](/en/runtime/dashboard) for setup.
