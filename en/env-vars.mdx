## Thine Runtime gateway

Set automatically by `thine` and `thine-runtime launch`:

| Variable | Description |
| --- | --- |
| `ANTHROPIC_BASE_URL` | Gateway URL (default `http://127.0.0.1:8787`) |
| `ANTHROPIC_AUTH_TOKEN` | Gateway auth token (default `thine`) |
| `ANTHROPIC_API_KEY` | Empty string — gateway uses provider keys |
| `THINE_RUNTIME_CONFIG` | Override config file path |
| `THINE_BIN` | Override `thine` binary path |
| `THINE_DISABLE_AUTO_ESCALATE` | `1` → disable model escalation middleware |
| `THINE_DISABLE_AUTO_INDEX` | `1` → skip launch-time workspace indexing |
| `THINE_AUTO_ESCALATE_MODEL` | Override escalation target model |
| `THINE_AUTO_ESCALATE_AFTER_TURNS` | Turns before escalation (default 3) |
| `THINE_TELEMETRY_POSTGRES_URL` | Override Postgres URL for dashboard |
| `THINE_BENCHMARK_MIDDLEWARE` | JSON merge into middleware flags |
| `THINE_RUNTIME_DEBUG` | `1` → log middleware notes to stderr |

## Provider API keys (runtime)

| Variable | Backend |
| --- | --- |
| `GEMINI_API_KEY` | `backend.type: gemini` |
| `OPENAI_API_KEY` | `openai-compatible`, `openai-responses` |
| `ANTHROPIC_API_KEY` | `anthropic-forward` only |

Keys are read from the environment — not stored in `config.json`.

## Provider selection (legacy Thine fork only)

These apply to the legacy legacy Thine fork, not the runtime gateway path:

| Variable | Description |
| --- | --- |
| `CLAUDE_CODE_LLM_PROVIDER` | `gemini`, `openai`, `deepseek`, `qwen`, `kimi`, `glm`, `ollama`, `openai-compatible` |
| `CLAUDE_CODE_USE_GEMINI` | `1` → Gemini backend |
| `CLAUDE_CODE_USE_OPENAI` | `1` → OpenAI backend |
| `CLAUDE_CODE_LLM_MODEL` | Override main loop model |
| `GEMINI_API_KEY` | Google Gemini API key |
| `OPENAI_API_KEY` | OpenAI API key |
| `DEEPSEEK_API_KEY` | DeepSeek API key |
| `ZHIPU_API_KEY` / `GLM_API_KEY` | Zhipu GLM |
| `MOONSHOT_API_KEY` | Kimi / Moonshot |
| `DASHSCOPE_API_KEY` | Qwen / DashScope |
| `THINE_API_KEY` | Generic Thine API key alias |

## Model overrides

| Variable | Description |
| --- | --- |
| `GEMINI_MODEL` | Default Gemini model |
| `OPENAI_MODEL` | Default OpenAI model |
| `ANTHROPIC_MODEL` | Remapped to universal model when not on first-party |

## Build / behavior

| Variable | Description |
| --- | --- |
| `CLAUDE_CODE_SIMPLE` | Lean external build |
| `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS` | Disable Anthropic beta headers |
| `CLAUDE_CODE_SAFE_MODE` | Set by `--safe-mode` |
| `CLAUDE_CODE_TRANSCRIPT_CLASSIFIER` | Enable auto-mode classifier |
| `TAVILY_API_KEY` | Web search for universal LLMs |
