## Recent highlights

### Thine Runtime

- **Workspace indexer** — `thine index` builds `.thine/index/workspace.json` for repository graph middleware
- **Model escalation** — auto-escalate to stronger model on stalled knowledge-read tasks
- **Read-error loop guard** — middleware hint after consecutive Read failures
- **Thine dashboard** — session-grouped telemetry at `/__thine`
- **Middleware suite** — instruction cache, tool pruning, persistent memory, kv cache

### Thine agent

- **`thine mcp login` / `logout`** — OAuth for HTTP/SSE MCP servers from the shell
- **Shell mode** — `! npm test` runs bash and can explain output
- **`/rewind` after `/clear`** — resume from before a clear
- **`/goal`** — set a completion condition; agent keeps working until it holds
- **`/cd`** — change working directory mid-session
- **`--safe-mode`** — troubleshooting mode without customizations
- **`--fallback-model`** — model fallback chain in print mode
- **`--plugin-url`** and **`.zip` `--plugin-dir`** — load plugins from archives

## Thine-specific

- **Multi-provider LLM** — Gemini, OpenAI, DeepSeek, Qwen, Kimi, GLM, Ollama ([Providers](/en/providers))
- **API-key auth** — use your provider keys, not a single-vendor subscription
- **Thine middleware** — token-efficient gateway optimizations
- **Thine Agent SDK** — `query()` with subprocess runtime
