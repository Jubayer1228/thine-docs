## Primary commands

| Command | Description | Example |
| --- | --- | --- |
| `thine` | Interactive Thine agent session | `thine` |
| `thine -p "query"` | Print response and exit | `thine -p "summarize README"` |
| `thine --no-middleware` | Gateway passthrough only | `thine --no-middleware -p "…"` |
| `thine doctor` | Health, backend, middleware routes | `thine doctor` |
| `thine index` | Build `.thine/index/workspace.json` | `thine index --force` |
| `thine-runtime start` | Run Thine Runtime (foreground) | `thine-runtime start` |
| `thine-runtime doctor` | Gateway health check | `thine-runtime doctor` |
| `thine-runtime launch` | Launch Thine agent with gateway env | `thine-runtime launch` |
| `thine-runtime ide [folder]` | Open Thine IDE | `thine-runtime ide .` |
| `thine-runtime ide doctor` | Verify Thine IDE + extension | `thine-runtime ide doctor` |

`thine` sets `ANTHROPIC_BASE_URL=http://127.0.0.1:8787` and starts Thine Runtime if needed.

## Session commands

| Command | Description | Example |
| --- | --- | --- |
| `thine "query"` | Session with initial prompt | `thine "explain this project"` |
| `thine -c` | Continue most recent conversation | `thine -c` |
| `thine -r [id\|term]` | Resume session by ID or search | `thine -r abc123` |
| `thine --from-pr [n]` | Resume session linked to a PR | `thine --from-pr 42` |

## Extension commands

| Command | Description | Example |
| --- | --- | --- |
| `thine mcp` | Manage MCP servers | `thine mcp list` |
| `thine mcp login <name>` | OAuth login for HTTP/SSE MCP | `thine mcp login github` |
| `thine plugin` | Plugin marketplace commands | `thine plugin list` |
| `thine agents` | List configured agents | `thine agents --json` |
| `thine project purge` | Clean local project state | `thine project purge` |

## Common flags

| Flag | Description |
| --- | --- |
| `-p, --print` | Non-interactive mode; print result and exit |
| `--model <model>` | Model alias or full name for the session |
| `--fallback-model <model>` | Fallback chain in print mode (repeatable up to 3) |
| `--max-turns <n>` | Max agentic turns in print mode |
| `--dangerously-skip-permissions` | Bypass permission prompts (sandboxes only) |
| `--no-middleware` | Disable Thine Runtime middleware |
| `--safe-mode` | Disable plugins, skills, hooks, MCP, and project memory |
| `--plugin-dir <path>` | Load plugin from directory or `.zip` (repeatable) |
| `--mcp-config <json\|file>` | Inline MCP server config |
| `--add-dir <path>` | Extra directories for tool access |
| `--continue` / `-c` | Continue last session in cwd |
| `--resume` / `-r` | Resume by session ID |
| `--output-format text\|json\|stream-json` | Print mode output format |
| `--bg, --background` | Start as background agent in tmux |

## Gateway environment

Set automatically by `thine` / `thine-runtime launch`:

```bash
export ANTHROPIC_BASE_URL=http://127.0.0.1:8787
export ANTHROPIC_AUTH_TOKEN=thine
export ANTHROPIC_API_KEY=""
export GEMINI_API_KEY=...   # or OPENAI_API_KEY
```

Full list: [Environment variables](/en/env-vars).
