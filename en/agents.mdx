---
title: Agents
description: Manage Thine agent sessions — list agents, background sessions, and custom agents.
---

These features come from **Thine**, routed through Thine Runtime. No fork-specific build flags required.

## List agents

```bash
thine agents
thine agents --json
```

Shows built-in and custom agents, active sessions, and configuration.

## Agent view

Upstream **agent view** manages parallel background sessions in the Thine UI.


## Custom agents

Define agents via `--agents` JSON or project `.claude/agents/`:

```bash
thine --agents '{"reviewer":{"description":"Reviews PRs","prompt":"You are a code reviewer"}}'
```

## Background sessions

```bash
thine --bg "fix flaky tests in background"
```

Requires tmux (upstream `BG_SESSIONS` feature). Works when tmux is installed and Thine background mode is available in your Thine version.
