---
title: Automate with hooks
description: Run shell commands when Thine edits files, finishes turns, or needs input.
---

Hooks run external commands at lifecycle points — format on save, lint before commit, block dangerous bash.


## Example: format after edit

`.claude/settings.json`:

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          {
            "type": "command",
            "command": "prettier --write $FILE_PATH"
          }
        ]
      }
    ]
  }
}
```

## Conditional hooks

Use `if` conditions (upstream week 13+) to match tool input patterns.
