title: Hooks reference
description: Hook events, configuration schema, and JSON formats for Thine.
---

Thine hooks work unchanged through Thine Runtime.


## Common events

| Event | When |
| --- | --- |
| `PreToolUse` | Before a tool runs |
| `PostToolUse` | After a tool completes |
| `UserPromptSubmit` | User sends a message |
| `Stop` | Agent turn ends |
| `SessionStart` | Session begins |

## Configuration location

- `.claude/settings.json` (project)
- `~/.claude/settings.json` (user)
- Managed settings for teams

## Environment

Hooks receive `CLAUDE_PROJECT_DIR`, `CLAUDE_EFFORT`, and session metadata from Thine.
